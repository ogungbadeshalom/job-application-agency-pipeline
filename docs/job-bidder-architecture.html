Job Bidder — System Architecture

Multi-tenant AI job-application agency · $0 self-hosted (PM2 + Cloudflare)

Data Flow — Refill

  • • Admin/Worker clicks Refill → POST /api/scrape
  • • Next spawns JobSpy (Python) → JSON → dedupe by URL
  • • AI role-fit gate (rule + borderline) filters matches
  • • 1-per-company → insert into jobs (saved)

Data Flow — Tailor & Apply

  • • Worker opens job → Tailor Resume (AI → JSON → PDF)
  • • Answer Question → AI answer → save to library
  • • Mark Applied → status_changed_at → weekly earnings

Roles & Zero-Cost

  • • Admin: manage clients/workers, scrape, AI config
  • • Worker: tailored apply for 1 client, self-refill, earnings
  • • Client: read-only applied jobs + tailored resumes
  • • $0: self-hosted Postgres, free AI (deepseek-flash), tunnel
